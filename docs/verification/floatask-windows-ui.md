## 三、已知限制（实现时登记）

- 保存设置会顺带执行历史保留清理（`applySettings` → `history.purge`），
  属可感知副作用、无提示；如需收紧为"仅保留期限变化时清理"另开任务。
- 首次配置向导：标题栏 X 直接关窗会丢失未保存的密钥输入（"稍后配置"会先落盘）。
- 重新识别确认守卫只挂在"重新框选"按钮；Alt+Q/托盘路径不经确认（ledger Task 5）。
- 停靠状态不持久化：重启后工具栏恢复浮动展开态（ledger Task 6）。
- live region 播报去重窗 1500ms：同语种同文本的错误在 1500ms 内连续发生
  （仅"立即重试又立即失败"的极端路径）会被去重吞掉一次播报；错误卡片视觉
  反馈不受影响。如需"两次 error 之间必须隔一次非 error 才去重"另开任务。
- 减少动态下 `.card` 内所有过渡与动画直接到最终状态；面板展开不再有滑动。
