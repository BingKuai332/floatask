欢迎使用

框一下，就懂了。

选中任何软件或网页上的一段内容，浮问会结合上下文，用几句话说清它是什么、有什么用。之后还可以在这个小窗口里继续追问、联网核查。

  1. 1填一个模型服务的 API Key
  2. 2按 Alt+Q 框选屏幕
  3. 3在浮窗里继续追问
获取 DeepSeek Key ↗ 也可以使用本地 Ollama，数据不出本机。

模型服务

任何 OpenAI 兼容接口都可以接入。解释质量主要取决于这里的模型。

DeepSeek

联网检索

解释时先搜索网页，再让模型结合资料回答，并列出出处。

联网时会把你框选的文字片段作为搜索词发送给搜索引擎。若内容涉密，请关闭联网。

使用方式

快捷键在全局生效；悬浮球可以拖动到顺手的位置。

悬浮球

历史记录

每次解释与追问自动保存在本机，可查看、收藏、搜索，并继续对话。

关闭后新的会话不再记录，已有记录仍会保留。

字体与阅读

选择字体、字号和行高；可以只改解释内容，也可以应用到整个界面。

当前阅读字体 系统默认 12.8px · 行高 1.72

字体列表来自 Windows 已安装字体；安装新字体后重新打开字体窗口即可看到。

隐私说明

哪些数据留在本机，哪些会发出去。

  • 截图只用于本机 OCR；只有开启“截图理解”时，压缩后的截图才会发送给你配置的模型服务。
  • 识别文字会发送给模型服务；开启联网时，搜索词片段会发送给搜索引擎。
  • API Key只保存在本机，使用 Windows 系统加密（DPAPI），不会发送给除模型服务之外的任何地方。
  • 浮问没有自建服务器，也不收集使用数据。
